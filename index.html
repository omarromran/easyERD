QUICK START

Build your ERD in minutes

1. Add tables

Click ＋ beside Tables, then rename the table and add its columns.

2. Define columns

Set the data type, primary key, uniqueness, nullability, default, and order.

3. Connect tables

Select a table, choose ＋ beside Relationships, then select the exact FK and referenced columns.

4. Save and share

Your work saves locally. Export JSON to move the editable project to another device.

Tips & tricks
  • Use singular table names and consistent snake_case names.
  • Every relationship should point from a foreign key to a primary or unique key.
  • Use Fit for a clean overview; drag the canvas to pan and pinch to zoom.
  • Use Ctrl/Cmd + K to search instantly. Use JSON as your backup format.
  • Review generated SQL before running it in a database.
